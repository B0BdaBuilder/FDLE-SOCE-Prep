# FDLE Corrections SOCE Prep

An original, from-scratch practice exam system for the FDLE Corrections State Officer Certification Examination (SOCE), built from:

- *Florida Basic Recruit Training Program: Corrections, Volume 1 [2025.07]*
- *Florida Basic Recruit Training Program: High Liability, Volume 2 [2025.07]* (First Aid, Firearms, and Defensive Tactics chapters)

**This is not an official FDLE product** and is not affiliated with or endorsed by FDLE. It is an independent study tool created for personal and class use.

## What's inside

A single self-contained HTML file (`index.html`) with:
- 533+ original, sourced practice questions across all 12 FDLE Corrections curriculum areas (CJK 0301, 0355, 0306, 0111, 0327, 0321, 0324, 0326, 0336, 0031, 0040, 0051)
- Quick Quiz mode (choose question count and subject areas)
- Full Practice Exam mode
- Per-subject, per-difficulty, and per-question-type performance breakdowns
- A remediation quiz generator based on repeatedly missed concepts
- Every question cites its source chapter/lesson, and statute- or case-law-based questions cite the specific F.S. section, F.A.C. rule, or case name

## Using it

Just open `index.html` in any browser, or visit the hosted link (see repo settings / Netlify for the live URL).

Progress (quiz history, scores) is stored locally in your own browser session and is not shared between devices or with other users.
